# Images

Drop your own images here, matching the filenames already referenced in the site:

- `profile.jpg` — your photo, referenced in `src/data/site.ts` (`avatar`). Optional: the hero doesn't currently render it, but it's wired up if you want to add a portrait later.
- `projects/digitel.jpg`
- `projects/bengali-bert.jpg`
- `projects/mind.jpg`
- `projects/parking-lagbe.jpg`
- `projects/redforce.jpg`

Any image you don't have yet: just delete the corresponding `image:` line from that project's YAML file in `src/content/projects/`, and the card will render without a photo.

Recommended size: ~1200×675px (16:9), JPG or WebP, kept under ~300KB each for fast loading.
